# TABLEAU_STUDENT-PERFORMANACE-DASHBORAD
TABLEAU_STUDENT PERFORMANACE DASHBORAD
Project Title: Student Performance Executive Dashboard
Main Objective:
Analyze student academic performance and identify how factors such as parent education, lunch type, test preparation, sports, study hours, and student demographics affect scores.
Technology Used:
Tableau
Tableau Workbook (.twbx)
Calculated Fields
Interactive Charts
Filters and Tooltips
Data Visualization
Dataset:
The project uses a student scores dataset containing:
Gender
Ethnic Group
Parent Education
Lunch Type
Test Preparation
Parent Marital Status
Sports participation
First-child status
Number of siblings
Transport
Weekly study hours
Math Score
Reading Score
Writing Score
Important Dashboard/Charts:
KPI – overall performance indicators
Parent Education vs Lunch Type
Test Preparation Impact
Math vs Reading Scatter Plot
Sports Performance
Study Hours Analysis
Student Profile Tooltip
Important Calculations:
Total Score = Math + Reading + Writing
Average Score = Total Score ÷ 3
Pass/Fail or At-Risk Classification
Average-performance calculations
Percentile/ranking calculation
Pass/At-Risk Logic:
The workbook classifies students using an average-score threshold:
60 or above → PASS
Below 60 → AT RISK / FAIL

Test Preparation Analysis:
Students are separated into:

Test prep completed
Test prep not completed

This allows comparison of academic performance between the two groups.

Study Hours Analysis:
Weekly study hours are categorized into:
Less than 5 hours
5–10 hours
Greater than 10 hours
Not specified
Math vs Reading Analysis:
The scatter plot compares Math Score and Reading Score to identify relationships between the two subjects.
Sports Analysis:
The dashboard examines sports participation against student performance.
Parent Education Analysis:
Parent education is compared with other student factors such as lunch type and academic performance.
Interactive Features:
Tableau allows users to interact with the visualizations through filters, selections, tooltips, and dashboard interactions.
Calculated Fields are Important:
The project demonstrates Tableau's ability to create custom metrics instead of relying only on raw dataset columns.
Business/Academic Value:
The dashboard can help identify performance patterns, students at risk, study behavior, and factors associated with academic results.
